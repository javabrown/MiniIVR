MiniIVR

Folder layout:

MiniIVR/
├── Dockerfile
├── run.sh
└── generated/
    ├── menu.wav
    ├── sales.wav
    ├── support.wav
    ├── invalid.wav
    └── 99-mini-ivr.xml   (generated by run.sh)

Run:
  chmod +x run.sh
  ./run.sh

The WAV files are already included. They are 8 kHz, mono, 16-bit PCM WAV files,
which is suitable for a basic telephony/IVR POC.
