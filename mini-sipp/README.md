
Mini-Sipp support SIP over UDP, configurable IP addresses and ports, basic call setup and teardown, multiple sequential calls, SIP message logging, and SDP offers.

<img width="753" height="431" alt="image" src="https://github.com/user-attachments/assets/a23a4ee2-977a-4791-b4d0-8d765f7a0730" />

```
java MiniSipp \
  --host 192.168.0.109 \
  --port 5060 \
  --from 1001 \
  --to 5000 \
  --duration-ms 3000

```
